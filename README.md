# Dashboard de Violencia Intrafamiliar

Este proyecto consiste en el desarrollo de un dashboard interactivo para el análisis de datos de violencia intrafamiliar, con el objetivo de identificar patrones y apoyar la toma de decisiones mediante visualizaciones claras.

---

## Objetivo
Analizar registros de violencia intrafamiliar utilizando técnicas de minería de datos y visualización, permitiendo explorar tendencias, factores de riesgo y distribución de los casos.

---

## Enfoque del proyecto
El análisis se basa en:
- Distribución temporal de los casos  
- Características de víctimas y agresores  
- Relación entre las personas involucradas  
- Identificación de zonas críticas  
- Factores de riesgo y tipos de violencia  
- Análisis de texto (NLP) para encontrar patrones en descripciones de los hechos  

---

## Tecnologías utilizadas
- Python  
- Flask  
- Chart.js  
- Orange (para preprocesamiento y análisis de datos)  
- Pandas  

---

## Funcionalidades del dashboard
- Visualización de indicadores clave (KPIs)  
- Gráficas de tipos de violencia  
- Tendencia mensual de casos  
- Estructura preparada para integrar datos reales  

---

Fuente de datos
- Datos Abiertos Colombia  
- TerriData (DNP)
